# Command Array

Термінальна аркада на реакцію: виконуйте показані комбінації напрямків якомога швидше, набирайте серії та піднімайтеся якомога вище за рівнями складності.

## Запуск

Потрібен Python 3. У PowerShell, з папки проєкту, виконайте:

```powershell
python main.py
```

## Як грати

На екрані з'являється команда зі справжніх стрілок: `↑` вгору, `↓` вниз, `←` ліворуч, `→` праворуч. Натискайте відповідні стрілки або `W`, `A`, `S`, `D` у тому самому порядку.

Поточна стрілка показана блакитним. Уже правильні стрілки стають зеленими. Якщо помилитися, прогрес повертається на початок, але комбінація лишається тією самою: її треба ввести заново.

Кожен рівень має власний таймер, який поступово спливає на екрані. Помилка забирає ще 4 секунди. Перед стартом рівня натисніть Enter або Space.

## Рівні

Кількість рівнів необмежена, але кожен рівень є окремим етапом. На ньому потрібно викликати 10 стратагем до завершення таймера. Рівень 1 має 42 секунди; кожен наступний дає на 3 секунди менше, до мінімуму 16 секунд.

Базова довжина команди поступово зростає: 3 стрілки на рівнях 1-2, 4 на рівнях 3-4, 5 на рівнях 5-6 і так далі. Окрім звичайних команд, на будь-якому рівні можуть трапитися складні стратагеми на 1 або 3 стрілки довші. Тому вже на першому рівні іноді з'являється довга послідовність. Довгі комбінації автоматично переносяться на наступний рядок.

## Керування

| Клавіша | Дія |
| --- | --- |
| Стрілки або `W`, `A`, `S`, `D` | Ввести напрямок |
| `Enter` або `Space` | Почати рівень |
| `Q` | Завершити гру |
| `R` | Почати нову сесію після завершення |

## Очки та завершення

- Правильна команда дає очки за рівень, бонус за поточну серію та бонус за час, що залишився.
- Кожна неправильна клавіша забирає 4 секунди, скидає серію та повертає прогрес поточної комбінації на початок.
- Гра завершується, коли спливає час поточного рівня. Наприкінці показуються фінальні очки, кількість команд, найкраща серія та досягнутий рівень.
- `COMBO` показує поточну серію виконаних команд, `BEST` - найкращу серію за сесію.

## Рекорди

Після завершення кожної сесії результат записується у `high_scores.json` у папці гри. Екран Game Over показує таблицю трьох найкращих результатів за очками. Для кожного запису доступні очки, рівень, кількість виконаних команд і найкраща серія.

На Windows клавіші читаються без Enter. Гра не використовує матеріали, звук чи код сторонніх ігор.
